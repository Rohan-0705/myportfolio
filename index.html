About

Hi, I'm Rohan, a passionate web developer focused on building modern and responsive web applications. I work with JavaScript, React, Node.js, Express.js, MongoDB, and MySQL. I enjoy developing both frontend interfaces and backend APIs and understanding how different parts of an application work together. I'm continuously improving my skills by building real-world projects, practicing problem-solving, and learning backend development, databases, authentication, and system design. My goal is to become a strong full-stack developer and build applications that are useful, reliable, and easy to use.
